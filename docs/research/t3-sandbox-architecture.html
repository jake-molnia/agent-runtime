Boundary blocker · MCP points at the wrong host

The current registry advertises loopback and retains credentials in memory. A worker-local, session-scoped forwarding endpoint must support central reauthorization, ACP stdio bridging and callback correlation. Changing only the hostname is insufficient.

Storage blocker · deleting a sandbox can delete its generated PVC

Start with separately owned retained PVCs referenced by direct Agent Sandbox resources. Generated volume-claim templates and claim expiry Retain do not establish the required lifetime. Warm-pool adoption needs a separate storage proof.

Correctness blocker · retrying a checkpoint can rewrite history

Current capture unconditionally updates the hidden Git ref. A response lost after capture can make a retry store later edits under the same checkpoint. Capture must return the original immutable result for the same operation.
